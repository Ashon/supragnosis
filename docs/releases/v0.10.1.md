Changes since v0.10.0.

**Upgrade the server and the app, then restart once; a pinch follows the fingers, and a join pins.**
`brew upgrade`, then `supragnosis restart`. The store format, the sync protocol and `status --json`
are unchanged, and a machine that joined a hub under v0.10.0 keeps syncing with it.

## Read before upgrading

- **A new join needs this release on both machines.** A code now starts `sgjoin2-`. This release
  says a v0.10.0 code was made by an older release, and v0.10.0 says a code from this one was made
  by a newer release: update the other machine, then make a new code.
- **A join pins the hub's certificate, whatever made it.** The code carries the certificate's
  fingerprint, and the joining machine accepts that certificate alone, during the join and after
  it. v0.10.0 checked a public CA's certificate by name instead. A machine that joins from now on
  stops syncing with a hub whose certificate is renewed, until it joins again; one that joined
  under v0.10.0 keeps the check it had.

## Fixes

- **A pinch zooms as far as the fingers spread.** On a trackpad, a pinch on the map scaled it far
  past the gesture: ten small pinch events took it from 1 to 0.31 where the fingers asked for
  0.82. A pinch now moves the map one to one, WebKit's gesture events included. A mouse wheel's
  notch is unchanged.
- **A write commits whole.** `observe`, `define_type`, `propose` and `review` write their log row
  and what it projects in one transaction, so a crash between the two leaves nothing for the next
  open to repair. Six kills at random points in a burst of 60 writes left each graph equal to its
  log and nothing owed.
- **The credential crosses only a verified connection, on every path.** The server check behind
  `supragnosis server` and Settings sent the credential with a client that honored a proxy and
  followed redirects; it uses the bridge's client now. An address edited by hand in `client.toml`
  to plain `http://` on another machine was used without the check `server add` makes; it is
  checked on every read.

## Pairing, smaller

The join's answer travels over the connection pinned to the hub's certificate, which keeps it
private and whole, so the seal on the credential, its one-time key, the nonces and the signature
on the answer are gone. The request carries the joining machine's signature, and the hub gives its
answer only to that machine. A hub upgraded from v0.10.0 drops the invitation records that release
kept in its own shape. About 500 lines went.

## Under the hood

- The CLI and the app no longer carry branches for Windows, which no release built: the app runs
  on macOS, and the CLI and the daemon on macOS and Linux.
- An app pointed at a remote server's profile says that its window shows the Mac's own knowledge,
  and that Settings > Server > This Mac switches back.
- docs/principles.md names the tension between assurance and proportion (Appendix A), and
  CLAUDE.md the rules that came with it: build for the person using it now, one review per step.
