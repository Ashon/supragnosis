Changes since v0.8.1.

**Upgrade the app and the server, then restart once; recover in one click, and drags follow.**
`brew upgrade`, then `supragnosis restart`. The app and the viewer changed. The store, the sync
protocol, the MCP tools and `status --json` are unchanged.

## A failed start offers the way back

A daemon that could not open its store - indexed by another search model - left the app's window on
its starting page, which said to open Settings > This Mac > Restart, and a restart failed the same
way. Recovering took a terminal.

The starting page now says why and offers one button. For a store indexed by another model it reads
"The search index needs rebuilding", with both models, and **Rebuild index** opens Settings and
starts the rebuild: the daemon stops, the index is removed, and the daemon starts again and embeds
every observation and entity with the model it runs. A start that failed for any other reason
offers **Open This Mac**, where Restart is. Setup's server step offers Rebuild index too. The
starting page itself holds no command, since it is at the viewer's address; Settings starts the
rebuild only while the daemon still cannot open its store.

## A dragged node stays under the pointer

Every report from the layout wrote each node's position back, the one being dragged too, with where
the layout last heard it was. In the app's engine a node dragged at the fitted view fell behind the
pointer from the fifth move and was 129 pixels away after fifteen. A report now leaves the held node
where the pointer put it, and letting go tells the layout where the node was let go. The node is at
the pointer at every move and at the release; after it, the layout settles it among its neighbours,
as before.

## Claude Code is back in AI apps

Since v0.7.0, Settings > AI apps showed `[object HTMLDivElement],[object HTMLDivElement]` where
Claude Code and its capture switch should be, whenever Claude Code was connected through the
bridge. Its two rows were a list inside the list of rows, and the page's element helper turned the
inner list into text. They are rows again, and the helper now flattens any depth of children.
