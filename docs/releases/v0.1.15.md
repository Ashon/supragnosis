Changes since v0.1.14.

A viewer/UX release. It refines how the observation log (v0.1.14) reads, and makes the minimap a
faithful miniature of the graph.

The changes are viewer-only (the viewer is embedded in the server binary) - no id-formula or
store-schema change, so no migration is needed. Upgrade is the usual `brew upgrade`, then
`brew services restart supragnosis-server`.

## Highlights

### An observation detail card, and tidier log rows
The log (the workspace Log tab and the node inspector's log column) reads as a compact, content-first
list now: a quiet meta line - trust tier as a colored dot plus a compact time - sits over the
observation content. The earlier cramped in-column expansion is gone. Clicking a row opens a focused,
dismissable detail card with the whole observation: full content, every provenance attestation (host,
on-behalf-of, claimed and evaluated tier, confidence, time, origin node), lineage (derived_from), and
the entities/relations it asserted - click an entity chip to focus its node. It is one detail
surface, shared by both the log column and the Log tab; close it with Escape, a backdrop click, or
the X.

### The minimap reflects the graph
The minimap is a faithful miniature now, not a field of uniform dots. Nodes are sized by degree (a
hub reads bigger), edge connections are drawn, and hyperedge hulls appear - reusing the graph's exact
rounded-hull geometry via a world-to-minimap transform, so the smooth corner-wrapping matches the
main canvas rather than a coarse polygon. The panel also picks up the same backdrop blur as the other
glass panels, so it sits in the same visual language.
