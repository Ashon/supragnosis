supragnosis v0.9.0

Upgrade the server and the app, then restart once; Review closes the loop, and every act says where.

Changes since v0.8.2.

Upgrade the server and the app, then restart once; Review closes the loop, and every act says where. brew upgrade, then supragnosis restart. The app, the viewer, the daemon and some MCP answers changed. The store gains one table, format 3, which v0.8.2 still opens: min_reader stays 2. The sync protocol and status --json are unchanged.

Read before upgrading

Four changes can surprise an agent, or a store an earlier build wrote:

  • A tool error is flagged. An MCP answer that is a top-level {"error": ...} object now carries isError, MCP's own convention for a failed call. The text is the same; a client that read it from an unflagged result now sees the call as failed. A not-found answer is still a result.
  • A type change or a recall cannot be merged yet. Neither kind has a commit effect, so a merge of one was taken and reported as done while it changed nothing. review now refuses it on every surface and says why, and the fold reads such a merge already in a log as a comment, so that proposal reads open again. Comment, reject and withdraw work as before.
  • * is a view, never a place to write. observe, propose and define_type refuse *, all and an empty workspace name, which earlier builds took as a workspace of that name. Every read still takes * for all workspaces.
  • A proposal stays in its workspace. A merge across two workspaces, a gate act on another workspace's observation, and a split filed away from its merge are refused, and one an earlier build took reads Blocked, or Rejected if someone rejected it. A verdict counts only in its proposal's own workspace; one filed elsewhere is listed under Health.

Review closes the loop

  • A decision leaves Needs you at once. Every reverse is on its Decided item and in the notice right after it: Un-merge, Accept after all, Undo confirmation. Decided says what was decided, in names.
  • A confirmation says what it confirms: each value's sources, the source you choose, how far its trust reaches, and the diff before you act. Confirm, then Undo, then Confirm again now confirms; before, the third act landed on the first and changed nothing.
  • Evidence sits where you decide: each entity's supporting observations, who asked and which app wrote it, and every check in words.
  • Same as... names two entities of one workspace as one, and a merge offers Keep ... instead. Un-merge opens the split it proposes, ready to accept.
  • What waits elsewhere is counted. When the default workspace holds little, the page opens on all workspaces; a scoped Review says how many items wait in the others, and the pill says "3 wait elsewhere". Blocked items can be rejected together, each listed with the check that holds it.
  • An act that lands on a proposal already there says what it found. Suggestions stop offering a pair you rejected, until something new is said about one of them.

The map keeps your place, and explains itself

  • Follow waits while you use the map. The selection lives in the address, with a history and a way back, and Esc gives the camera back.
  • The map has a key: counted chips with Only and Show all, one color per type across the store, trust toggles that dim, a hover card, and one word for a region.
  • Search clears on a choice, offers your recent searches, names each hit's workspace, and "Show these 13 on the map" holds the answer as a working set. Map | List switches the window to a table.
  • Single keys zoom, fit and open List and the Keys dialog; View holds what changes the picture.
  • Each entity says when it was last said, and a Said filter dims what was not said today, in the last 7 days, or since your last visit.
  • The same name in another workspace is said on the sheet and lit under All.

On a phone and a tablet

One finger moves the map and two zoom it, the page opens on the map, the inspector is a sheet with two heights, and the camera buttons sit above it. From 760 to 1200 pixels a floating panel now ends above the camera toolbar under a finger, and at 200% text, as it did with a mouse.

The app

  • The app menu gains Setup..., Find, View's map commands and Help. The tray says the memory's state and offers its act, and its icon changes shape only when the memory cannot be used. Quit says it stops the memory.
  • Settings keeps its last pane, a dot marks AI apps when one needs you, and the window keeps its size and place.
  • The app's pages keep focus across a redraw, and a failure says so, with Restart, Diagnostics and the log.
  • The app that wrote an entry is recorded beside it on this Mac and said in the who-line ("Agent - Claude Code on this Mac"); it is never sent to a peer or the read tier.
  • Try it quotes the first entry and opens the graph on it. supragnosis connect knows OpenCode.

For agents

  • Every write answers with the workspace it wrote to. An observe that makes a new workspace adds a note naming the workspaces that hold knowledge, nearest name first.
  • Entity search hits carry name, type and workspace; get_entity says when an id looks like a name.
  • list_proposals and get_proposal name each proposal's workspace, a merged promotion's granted_tier, and no_effect_yet on a type change or a recall.
  • propose answers state and found, with a note when an identical proposal was already there: a proposal is its content.
  • A merged demotion lowers to the tier it asked for; it was capped by its surface.
  • The rules every prompt keeps say what to tell the person about a kind with no effect yet.

Fixes

  • A remote reader's map did not draw: the read tier answered the layout worker and the renderer as not served.
  • The minimap keeps its width round the frame's corner; an icon sits on its text's middle; no scroll container cuts a focus ring.
